快速开始

字数 1,600 字 时长 5 分钟
!
已知限制

Web 教室端无法在无用户手势时进入系统全屏，通知会以覆盖整个页面的方式展示；Android 后台保活也受系统限制。教室大屏建议使用 Windows 客户端。

校联由三个部分组成：Hub、教室端和教师端。Hub 是运行在常开电脑上的服务；教室端连接 Hub，接收通知和文件；教师端登录后发送内容。只使用一台 Windows 电脑也可以完成第一次体验。

安装与更新通道

所有发行文件都可以在 下载区获取，提供 GitHub 直连和镜像加速两条线路。Windows 安装包已经包含 Hub，Android 只需要教师端 APK。

Windows

运行 SchoolLink-Setup-0.2.0_dev.exe，按向导安装即可。安装器为当前用户安装，不需要管理员权限；教室端、教师端和 Hub 在同一目录下。

安装包目前没有商业代码签名，首次运行时 Windows SmartScreen 可能提示“未知发布者”。确认文件来自本项目 Releases 后，可以选择“更多信息 → 仍要运行”。

Android

下载 Universal APK 安装。首次安装需要允许当前文件管理器或浏览器“安装未知应用”。APK 使用项目签名密钥签名；如果系统提示签名冲突，请先卸载旧版本再安装。

Web

Web 端无需安装。打开 Hub 控制台显示的地址，例如 http://192.168.1.10:8421/，即可进入教室端或教师端。浏览器需要与 Hub 在同一个校园局域网内。

Linux

Linux 只提供 Hub 服务端。下载 SchoolLinkHub-linux.tar.gz 后解压，执行 sudo bash install.sh；脚本会配置 systemd、数据目录和防火墙端口。

启动 Hub

Hub 是一个纯 Dart 服务端，负责账号、班级、消息归档、文件存储和 Web 托管。建议部署在教室内或机房的一台常开电脑上，并设置开机启动。

Windows

安装后从开始菜单打开“校联 Hub 服务端”，或者在安装目录运行：

SchoolLinkHub.exe --port 8421 --data "%LOCALAPPDATA%\SchoolLinkHub" --web-root ".\web"

首次启动时，Hub 会检查 Windows 防火墙；如果缺少规则，会弹出一次 UAC，申请添加仅限本地子网的放行规则。拒绝 UAC 不会阻止 Hub 启动，但客户端可能无法从其他设备连接。

Linux

tar -xzf SchoolLinkHub-linux.tar.gz
cd SchoolLinkHub-linux
sudo bash install.sh

默认数据目录为 /var/lib/schoollink-hub，服务名为 schoollink-hub。脚本会自动处理 ufw 或 firewalld（如果它们处于启用状态）。

!
首次部署请修改默认凭据

默认管理员 PIN 为 246810，学校注册码为 SCHOOL26。部署完成后请立即在 Hub 管理台修改，并只把注册码发给校内教师。

教室端设置

教室端用于教室大屏，设计目标是“开机后只接收，不出现复杂入口”。第一次启动需要完成一次不可逆的教室绑定。

  1. 连接 Hub填写 Hub 地址，或点击“发现局域网服务器”自动寻找。
  2. 选择教室模式在用途页面选择“教室模式”。
  3. 选择年级与班级年级为高一、高二或高三，班级为 9–16 班。
  4. 确认锁定确认后，教室模式和班级不能在应用内修改；需要卸载重装或清除应用数据才能重置。

完成后，教室端会自动接收教师的通知和文件，并按老师展示历史会话。普通消息和教室回复不会触发全屏。

使用 Web 教室端时，推荐用 Edge kiosk 模式打开 Hub 地址：

msedge --kiosk --app=http://<Hub 主机 IP>:8421/

教师端登录

教师端支持 Windows 和 Android。第一次登录需要填写 Hub 地址、姓名、PIN 和学校注册码。登录成功后，只会显示你任教的班级。

  • 姓名和 PIN 由教师首次注册时设置，之后用同一组信息登录。
  • 学校注册码由管理员在 Hub 管理台配置。
  • 如果找不到任教班级，请让管理员在 Hub 管理台检查班级绑定。

发送通知

教师端有两种发送方式：普通消息和全屏通知。只有通知会触发教室大屏全屏，普通消息永久保持聊天形态。

类型是否全屏适用场景
普通消息否日常沟通、提醒教师查看文件
全屏通知是上课提醒、临时调课、重要事项
教室回复否教室向教师确认收到
  • 关闭方式：手动确认关闭，或 N 秒后自动关闭。
  • 提示音：发送时可选择是否在教室大屏播放提示音。
  • 发送范围：可发给当前班级，也可发给全部任教班级。

通知送达后，教室端会保留下通知历史；教师端也可以看到每一条通知的送达方式和教室回复。

文件接收

教师在会话中附加文件并发送后，教室端会自动保存，不需要学生或值班人员确认。文件消息会显示文件大小和保存状态，并提供“打开”和“定位”入口。

  • 文件通过 Hub 分发，Hub 必须在线；当前版本不支持在 Hub 离线时直接向教室端传文件。
  • Hub 默认保留文件 90 天，可在 Hub 管理台配置。
  • 发给多个班级时，Hub 只保存一份文件，教室端各自下载。

网络与防火墙

Hub 和客户端必须位于能够互相访问的校园局域网。Windows 首次启动 Hub 时会自动检查防火墙；也可以手动运行 tools/enable-firewall.ps1。

端口协议用途
8421TCPHub HTTP / WebSocket / Web
8421UDPHub 局域网发现
8422TCP原生端直连
8424UDP原生端发现

防火墙规则默认只允许本地子网（LocalSubnet）访问。如果学校网络划分了多个 VLAN，需要额外放行路由，或把 Hub 放在所有教室都能访问的网段。

使用 VPN 或虚拟网卡时，浏览器和客户端可能会拿到虚拟网卡的地址。请优先填写 Hub 所在的实际局域网 IP，而不是 VPN 地址。

数据与备份

Hub 保存账号、花名册、消息索引和文件。Windows 默认数据目录是 %LOCALAPPDATA%\SchoolLinkHub，Linux 默认是 /var/lib/schoollink-hub。

  • 请定期备份 Hub 数据目录，尤其是文件和消息记录。
  • 卸载 Windows 客户端会清除教室模式绑定和本地缓存，但会保留 Hub 数据目录。
  • 更换 Hub 电脑时，先停止 Hub，再整体迁移数据目录。

升级与重置

新版本可以直接覆盖安装，Hub 数据不会因为客户端升级而丢失。升级后重新打开客户端即可继续使用。

  • 重置教室模式：卸载并重新安装 Windows 客户端，或在系统中清除应用数据。
  • 重置 Hub：停止 Hub 后备份并清空数据目录，首次启动会重新生成默认配置。
  • 换设备：教师可以在新设备登录同一账号，原设备不需要特殊解绑。

常见问题

局域网内其他设备打不开 Hub

检查 Hub 是否监听在 0.0.0.0:8421，Windows 防火墙是否放行了 8421，以及设备是否在同一子网。使用 VPN 时先确认访问的是哪个网卡地址。

教室端选错了年级或班级

教室模式确认后不能在界面更改。卸载并重新安装客户端，或清除应用数据后重新设置。

Windows 提示“未知发布者”

安装包未做商业代码签名，SmartScreen 会提示。请从本项目 Releases 下载，并核对 SHA256SUMS.txt 后再运行。

Web 端点击通知没有系统全屏

浏览器不允许没有用户手势时进入系统全屏，因此 Web 端使用页面覆盖层展示通知。需要真正的教室大屏体验时请使用 Windows 客户端。

Android 教师端收不到消息

Android 后台保活受厂商策略限制。请允许应用后台运行并关闭电池优化；教室端应由 Windows 客户端长期保持前台。

文件没有自动保存

确认 Hub 在线、教室端磁盘有空间，并且文件还没有超过 Hub 的保留期限。可以在文件消息上点击“定位”查看本地保存位置。
