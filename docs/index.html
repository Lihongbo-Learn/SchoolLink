核心能力

通知、文件、会话，一套系统

从教师点击发送，到教室大屏亮起，再到文件落盘保存，整条链路在校园局域网内完成。

全屏通知

教师发送时逐条选择“手动确认关闭”或 N 秒自动关闭，可附带提示音。只有通知类型会触发全屏。

文件自动接收

教师上传一次，教室端自动保存，无需学生确认。文件经 Hub 分发给单个班级或全部任教班级。

混合网络

原生端优先通过局域网直连传递消息，同时向 Hub 归档；直连不可用时自动走 Hub，断网后重新补齐。

聊天与通知分离

普通消息和教室回复永不触发全屏。历史按老师归档，谁发过什么、谁确认过，都能回看。

教室模式锁定

首次启动选择年级与班级，确认后不可在界面更改。避免误触切换，卸载重装才能重置。

常开 Hub

纯 Dart 服务，负责账号、花名册、消息、文件、Web 托管与离线补发。Windows 与 Linux 均可部署。

两种模式

教室端专注接收，教师端专注发送

同一套客户端选择不同用途。教室端不出现复杂入口，教师端覆盖日常沟通和通知。

教室端

大屏只做一件事：不错过通知

  • 全屏通知，手动或自动关闭
  • 自动接收并保存教师文件
  • 按老师查看会话与通知历史
  • 可全屏预览重要通知
Windows 大屏优先 教室端
教师端

一个入口，覆盖单班与全部班级

  • 姓名 + PIN 登录，仅显示任教班级
  • 普通消息、全屏通知、文件一次发送
  • 逐条设置关闭方式与提示音
  • 发送记录与教室回复集中保存

快速开始

一台常开电脑，就是一个 Hub

把 Hub 部署在教室内或机房的一台常开电脑上，教室端与教师端连接它即可。网页端也由 Hub 直接提供。

阅读部署文档
  1. 01

    启动 Hub

    Windows 运行安装包内的 Hub，或使用 Linux 一键脚本。

  2. 02

    配置教室端

    首次启动选择年级与班级，并连接 Hub 地址。

  3. 03

    教师登录

    姓名 + PIN 登录，选择任教班级后即可发送。
